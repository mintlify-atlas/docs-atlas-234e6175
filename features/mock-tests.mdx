The mock test tracking system helps you log full-length and sectional tests, visualize score trajectories, and identify performance patterns. All mock data is displayed in the Analytics section.

## Logging mock test scores

You can log mock tests in two ways:

### Method 1: Through the daily planner

1. Go to the [daily planner](/features/daily-planner)
2. Select **MockTest** as the subject
3. Enter scores in the subject-specific fields that appear
4. Add task description (e.g., "JEE Main Full Length #12")
5. Submit the task

### Method 2: Through Analytics section

<Steps>
  <Step title="Navigate to Analytics">
    Click **Stats** in the navigation bar, then select **Mocks Data** from the dropdown menu.
  </Step>
  
  <Step title="Click Add Mock">
    Press the **+ Add Mock** button in the top-right corner.
  </Step>
  
  <Step title="Enter test details">
    Fill in the score fields and test description. The system auto-calculates total scores based on your exam type (JEE/NEET).
  </Step>
  
  <Step title="Submit">
    Click **Add Mock** to save the test to your history.
  </Step>
</Steps>

## Mock test analytics

The Analytics view displays four key statistics at the top:

- **Tests Taken**: Total number of mock tests logged
- **Avg Score**: Your average score across all tests
- **Best Score**: Your highest score achieved
- **Recent Trend**: Average of your last 5 tests (shows recent trajectory)

Each stat card uses a colored top border for visual distinction.

<Info>
**Interpreting trends**: Compare your "Recent Trend" to "Avg Score" to see if you're improving. If Recent Trend > Avg Score, you're on an upward trajectory. If it's lower, review your preparation strategy.
</Info>

## Performance trajectory chart

Below the statistics, the trajectory chart plots your mock test scores over time:

- **X-axis**: Test sequence (Test 1, Test 2, etc.)
- **Y-axis**: Score achieved
- **Line graph**: Shows score progression with data points
- **Subject filters**: Click subject pills above the chart to filter by specific subjects

### Chart features

- Hover over data points to see exact scores
- Filter by subject to analyze single-subject performance
- Visual trendline helps identify improvement or decline patterns

## Mock test history

The "Test History" section below the chart lists all your mock tests in reverse chronological order (newest first).

Each test card displays:

- Test description/name
- Subject badges
- Total score
- Date taken
- Delete button

### Filtering mock history

Use the subject filter pills to show only tests for specific subjects (e.g., only Physics mocks).

## Score tracking by subject

ChaosPrep automatically tracks subject-wise scores for JEE and NEET exams:

- **JEE**: Physics, Chemistry, Maths (separate scores)
- **NEET**: Physics, Chemistry, Biology (separate scores)

When you log a mock test, enter individual subject scores. The system stores these separately for detailed analytics.

## Mock test statistics calculation

- **Total tests**: Count of all logged mocks
- **Average score**: Mean of all total scores
- **Best score**: Maximum total score achieved
- **Recent trend**: Mean of last 5 test scores (or fewer if you have less than 5 tests)

All statistics update in real-time as you add or delete tests.

<Info>
**Growth tracking**: Take regular mocks (weekly is ideal) and watch your Recent Trend line. Consistent mock-taking with proper review creates the fastest score improvements.
</Info>

## Deleting mock tests

Click the trash icon on any test card in the history section to delete it. A confirmation dialog appears before deletion to prevent accidental removal.

## Mock test integration with daily tasks

Mock tests logged through the daily planner appear in both:

1. Your calendar view (as special MockTest task cards)
2. The Analytics section (for score tracking and charting)

This dual visibility helps you track both *when* you take tests and *how well* you perform.
